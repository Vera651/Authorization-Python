# Автоматизация тестирования SauceDemo с использованием Page Object и Allure

## Описание проекта

Проект содержит автоматизированный тест пользовательского сценария покупки товаров на сайте SauceDemo.

В проекте реализован паттерн **Page Object Model (POM)**:

- `LoginPage` — страница авторизации;
- `MainPage` — главная страница с товарами;
- `CartPage` — страница корзины;
- `CheckoutPage` — страница оформления заказа.

Для формирования отчётов о прохождении тестов используется библиотека **Allure Framework**.

#для запуска тестов с Allure отчетом испульзовать команду "python -m pytest --alluredir allure-result", результат сохранится в папку "allure-result"

allure serve allure-result
